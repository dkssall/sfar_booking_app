# تطبيق سافر - نسخة البداية

هذه نسخة أولية من واجهة تطبيق حجز مواعيد السفر، مبنية بـ Flutter وباتجاه RTL للعربية.

## التشغيل
1. ثبّت Flutter وAndroid Studio.
2. افتح هذا المجلد في Android Studio أو VS Code.
3. شغّل:
   flutter pub get
   flutter run

## الخطوة التالية
ربط الواجهات بقاعدة بيانات، تسجيل المستخدمين، شاشة الحجز، لوحة الإدارة، وإضافة السيارات من الإدارة فقط.
